# hxwl-01 验配预约复核台

门店听力师的验配预约登记、复核与时段占用工作台。

## 技术栈

React + Vite + TypeScript + CSS（无新增依赖）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101

## 功能

- **预约登记**：客户、耳别（左/右/双耳）、听力师、设备、时段；登记后一律先保存为待复核。
- **时段冲突**：同一听力师或同一设备在重叠时段只保留一单；冲突面板列出客户、听力师、时段与原值，可改期或取消其中一单。
- **儿童复核**：儿童验配未取得听力师授权，或近 30 天耳镜检查缺失时不得确认，只能保存为待复核。
- **改期**：先释放原时段（回到待复核并解冻），选择新时段后重新确认；确认后冻结客户、设备、听力师和时段。
- **一致占用**：预约、复核结果与时段占用由同一份本地持久化数据（localStorage）推导，刷新后保持一致；可一键重置示例数据。

## 目录结构（数据 / 规则 / 界面分层）

```
src/
  data/
    types.ts     # 类型定义
    catalog.ts   # 客户、听力师、设备、时段目录与种子预约
    store.ts     # localStorage 持久化
  rules/
    booking.ts   # 纯规则：时段重叠、冲突检测、儿童复核、确认/改期/取消状态转移
  ui/
    BookingForm.tsx    # 预约登记
    ReviewBoard.tsx    # 复核台（确认 / 改期 / 取消 / 待复核编辑）
    ConflictList.tsx   # 冲突列表（客户、听力师、时段、原值）
    OccupancyBoard.tsx # 时段占用看板（已确认预约）
  App.tsx        # 组装与状态管理
```
